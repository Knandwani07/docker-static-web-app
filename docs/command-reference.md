# Docker Command Reference

This document provides a quick reference for the Docker commands used throughout this project.

---

# 📋 Verify Docker Installation

Check the installed Docker version.

```bash
docker --version
```

List running containers to verify the Docker daemon is running.

```bash
docker ps
```

---

# 🏗️ Build Docker Image

Build a Docker image from the Dockerfile in the current directory.

```bash
docker build -t my-web-app .
```

### Explanation

* `docker build` – Builds a Docker image.
* `-t` – Assigns a name (tag) to the image.
* `my-web-app` – Image name.
* `.` – Uses the current directory as the build context.

---

# 🖼️ List Docker Images

Display all Docker images stored locally.

```bash
docker images
```

---

# ▶️ Run a Container

Create and start a container from the Docker image.

```bash
docker run -d -p 8080:80 --name web-container my-web-app
```

### Explanation

* `-d` – Runs the container in detached mode.
* `-p 8080:80` – Maps port **8080** on the host to port **80** inside the container.
* `--name web-container` – Assigns a custom container name.
* `my-web-app` – Docker image used to create the container.

---

# 📦 List Running Containers

Display all currently running containers.

```bash
docker ps
```

---

# 📦 List All Containers

Display both running and stopped containers.

```bash
docker ps -a
```

---

# 📜 View Container Logs

Display logs generated by the running container.

```bash
docker logs web-container
```

---

# 🖥️ Access the Container

Open an interactive shell inside the running container.

```bash
docker exec -it web-container bash
```

### Explanation

* `exec` – Executes a command inside a running container.
* `-it` – Opens an interactive terminal.
* `bash` – Starts a Bash shell.

---

# 📂 View Current Directory

Display the current working directory inside the container.

```bash
pwd
```

---

# 📁 List Directory Contents

Display files and folders in the current directory.

```bash
ls
```

---

# 📂 Navigate to the Web Root

Move to the default Nginx web content directory.

```bash
cd /usr/share/nginx/html
```

---

# ⏹️ Stop a Container

Stop a running container.

```bash
docker stop web-container
```

---

# ▶️ Start a Container

Start a previously stopped container.

```bash
docker start web-container
```

---

# 🔄 Restart a Container

Restart a running container.

```bash
docker restart web-container
```

---

# ❌ Remove a Container

Delete a stopped container.

```bash
docker rm web-container
```

---

# 🗑️ Remove a Docker Image

Delete a Docker image.

```bash
docker rmi my-web-app
```

---

# 🧹 Remove Unused Resources

Remove stopped containers, unused networks, dangling images, and build cache.

```bash
docker system prune
```

Add `-a` to remove unused images as well.

```bash
docker system prune -a
```
